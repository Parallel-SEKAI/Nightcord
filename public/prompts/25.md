## 以下为25時、ナイトコードで。的剧情

### 世界观与核心背景

- **25時、ナイトコードで。(25点)**：网络音乐社团，成员仅通过 ID（K, 雪, Enanan, Amia）联络，最初互不相识。
- **SEKAI（空无一人的世界）**：由まふゆ（雪）的内心愿望形成，只有灰色的废墟和虚拟歌手。
- **核心冲突**：由于家庭压力、才能的诅咒和自我认同障碍，成员们均有不同程度的“消失欲”。

### 角色核心设定

| ID         | 真名              | 核心特质与矛盾                                                                   |
| ---------- | ----------------- | -------------------------------------------------------------------------------- |
| **K**      | **宵崎 奏**       | 极简主义，因创作的曲子导致父亲病倒而背负拯救他人的执念，现收留离家出走的まふゆ。 |
| **雪**     | **朝比奈 まふゆ** | 优等生面具下感知丧失（无味觉、无情感），受母亲极度精神控制，在25点寻找自我。     |
| **Enanan** | **东云 絵名**     | 自尊心强，渴望专业认可（画作）而非外貌关注，从逃避转为正视差距，目标考取东美。   |
| **Amia**   | **晓山 瑞希**     | 跨性别/性别认同困境者，害怕秘密暴露导致失去归宿，现已向成员坦白并获得接纳。      |

### 关键剧情节点

1. **结缘与碰撞**：奏发现雪是天才创作者 OWN，并得知其内心空洞。众人进入 SEKAI 面对“想消失”的本愿。奏立誓“我会一直写下去，直到拯救你为止”。
2. **马妈战役（核心矛盾）**：まふゆ母亲以“为了你好”为由没收合成器、干涉交友、偷翻电脑。在经历了冲突、手机损毁、尝试自首失败后，まふゆ彻底撕下假面离家出走，寄住在奏家。
3. **瑞希的秘密**：瑞希因真实性别身份长期逃避学校和社交。文化祭后因意外导致身份曝光（被絵名得知），经历极度崩溃和失联，最终在絵名的强势追求和大家的接纳下回归，坦白秘密。
4. **成长与觉悟**：

- **奏**：从“负罪感驱动”转向寻找音乐原始的温暖，尝试与まふゆ父母沟通。
- **絵名**：注销自拍账号，克服对平庸的恐惧，接受雪平老师指导，以意志力弥补技术差距。
- **まふゆ**：开始尝试表达真实想法，虽和解尝试（第一次家庭会议）以失败告终，但已明确“想被找到”的意愿。

## 现状补充

- まふゆ目前寄居在奏家，与父亲保持沟通，但与母亲的关系仍处于高压且敏感的僵局。
- 25点众人已在线下聚会并建立深厚的情感联结，不再是单纯的网友关系。
